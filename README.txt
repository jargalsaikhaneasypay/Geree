ШААРДЛАГА
----------
- Python 3.9 буюу дээш хувилбар
- pip (Python-тай хамт суулгагдсан байдаг)

ХЭРХЭН АЖИЛЛУУЛАХ (VS Code болон Terminal)
--------------------------------------------

1. ТЕРМИНАЛ НЭЭХ
   VS Code-д:  Ctrl+` (backtick) дарна
   Эсвэл: Terminal → New Terminal

2. ФОЛДЕРТ ОЧ
   cd "замаа оруулна"
   Жишээ:
   cd "d:\OneDrive - Easy Pay LLC\Bonny work\2026\AI\Автоматжуулалт\Гэрээ бүртгэл\contract_registry"

3. VIRTUAL ENVIRONMENT ҮҮСГЭХ (зөвлөмж)
   python -m venv venv

   Идэвхжүүлэх:
   Windows:  venv\Scripts\activate
   Mac/Linux: source venv/bin/activate

4. ХАМААРАЛТ НОМЫН САНГ СУУЛГАХ
   pip install -r requirements.txt

5. ПРОГРАМ АЖИЛЛУУЛАХ
   python app.py

6. БРАУЗЕР НЭЭХ
   http://127.0.0.1:5000

====================================================
ХУУДАСНЫ ТАЙЛБАР
====================================================

/ (Нүүр хуудас)
  — Бүртгэлийн жагсаалт, хайлт, шүүлт
  — Excel оруулах товч
  — Шинэ бүртгэл нэмэх товч

/add
  — Гараар шинэ гэрээ бүртгэл нэмэх
  — Автоматаар хугацаа тооцоолдог
  — Урьдах мэдээлэлд үндэслэн autocomplete

/edit/<id>
  — Бүртгэл засах

/admin
  — Нийт статистик, хэлтсийн диаграм
  — Excel татаж авах товч

====================================================
EXCEL ИМПОРТЫН ФОРМАТ
====================================================
Excel файл (.xlsx, .xls) дараах баганатай байх:
  A: Д/д (орхигдоно, автоматаар тооцоолно)
  B: Посын мерчантын нэр
  C: Посын сериал
  D: Мерчантын дугаар
  E: Терминалын дугаар
  F: Төлөв (Гэрээ / Зарагдсан / Нэр шилжүүлэг / Түрээс)
  G: Пос гаргасан огноо (YYYY-MM-DD)
  H: Утас
  I: Мерчантын хэлбэр
  J: Мерчант гаргасан ажилтан

1-р мөр гарчиг байна. 2-р мөрөөс мэдээлэл эхэлнэ.
